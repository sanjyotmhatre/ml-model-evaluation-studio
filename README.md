# Ml Model Evaluation Studio

**Track:** AI/ML  
**Target level:** Intermediate → Advanced  
**Stack:** Python, scikit-learn, pandas, Streamlit

## Problem statement
A reproducible ML experiment workbench with leakage-safe splitting, preprocessing pipelines, cross-validation, metrics, and model cards.

## Design goals
- Clear separation between domain logic, interfaces, and infrastructure.
- Deterministic core logic where practical.
- Useful tests and documented failure modes.
- Reproducible setup with pinned or bounded dependencies.

## Quick start
See the project-specific setup below. Python projects use Python 3.11+ and a virtual environment. Flutter projects require the Flutter stable SDK. Embedded projects include a simulator-first path.

## Validation checklist
- [ ] Follow setup instructions from a clean environment.
- [ ] Run all automated tests.
- [ ] Try at least one edge case and one failure case.
- [ ] Record toolchain versions and actual results.
- [ ] Add screenshots, plots, or serial logs generated by your own run.
- [ ] Update the limitations section before publishing.

## Data / hardware integrity
Build a baseline, compare models, inspect errors, and record limitations. Dataset: scikit-learn breast cancer dataset (educational only; not for diagnosis).

## Roadmap
1. Complete the starter implementation and verify it locally.
2. Add tests for boundary cases and invalid input.
3. Add one experiment that answers a specific engineering question.
4. Record results with environment details.
5. Refactor based on what the results reveal.

## Limitations
This repository is a development starting point, not evidence of production deployment or validated real-world performance. Replace sample data and simulated inputs with properly sourced measurements before making real-world claims.
